## 三、独立验证的结论

**确认（有可复现证据）**

- 二极管 1501 点扫描：首次导通 0.701V、电流单调、**从不为负**；400 例模糊测试 0 个非无源元件，max|ΣP| = 1.4e-10W
- NPN `Ic=βIb` 与手算一致到 1e-9；`ΣP≈0` 在电阻网络与二极管网络都成立（~1e-18W）
- 免费绿灯审计可证伪：注入 c3-1 出厂值后**只有该关那条用例失败并点名**，还原后逐字节一致
- 44 关走线独立复算：覆盖 ≤0.0306、伴随 ≤28.5px、同网重合 ≤5.66px；239/239 折线保持 45°/90° 且端点不变
- 预览≡落线在 129 组真实配对上 0 处不一致；5 类非法连线全部被纯函数拦截；浏览器撤销/重做覆盖加元件与删线
- 关卡页验收台显示 `偏小 7.015 mA`（= 10 − (5−2)/(1000+5)）；结算能量账本 BT1 +66.7mW / RP1 −39.1mW / LED1 −27.6mW，ΣP 0.0pW
- 图鉴 8 处被修正的数值全部复算正确（晶振 26/15~18pF、保险丝 1.333×、ADC 0.806mV、555 685.71Hz/52.38%、迟滞 0.300V、LDO 227.5°C、CTR 5mA）
- 8 条路由浏览器实测 console 干净、无横向滚动；图解站点与独立页读数一致（100Ω 烧灯 109~118ms）

**被证伪（已修）**

1. 电位器在 `w=0/1` 时引擎钳位到 0.005/4.995V，而界面允许填 0/1、文档又写「0=靠 b 端」——
   三处口径不一致。已把 `PARAM_SCHEMA` 的上下限与引擎钳位对齐并加断言。
2. `wires-diag` 打印的"峰值覆盖 0.037 @ sb-4"是 2px 采样伪影；0.25px 复算为 sb-4=0.0291、真峰值 sb-5=0.0306。
   阈值结论不变，但**报告数字应以细采样为准**。

**无法验证 / 残留风险**

- 运放负电源轨悬空仍回落 0V（已知教学简化，`solver.test.ts` 里以"记录 bug"的方式锁定，未改行为）。
- NMOS/PMOS 仍为理想开关、保险丝瞬时熔断、未接电源的 MCU 静态电流记 0。
- 撤销/重做的 650ms 合并语义未做交互级自动化（仓库无 jsdom/@testing-library），仅浏览器手验。
- 44 关里只有 3 关做过逐关浏览器实玩（c1-4、c3-4、c5-2），其余靠测试与探针覆盖。
